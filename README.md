# ExamShield AI Showcase

Mobile-friendly static website and interactive local file-check demonstration for the ExamShield AI prototype.

## Publish with GitHub Pages

1. Upload all files in this repository root to the `EXAMSHIELD-AI` repository on GitHub.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the Pages deployment to finish. The public URL should be `https://petalchodanker2010-cpu.github.io/EXAMSHIELD-AI/`.

GitHub Pages is public. Do not add private documents, credentials, or real unreleased exam papers here. The demo uses the included fictional sample and performs file fingerprinting in the visitor's browser without uploading the selected file.

## Files

- `index.html`, `styles.css`, `app.js`: website and interactive demo.
- `MOCK-042.png`: demo sample.
- `ExamShield-AI-All-Browsers-v0.4.3.zip`: extension package bundle.
- `INSTALL.txt`: browser installation notes.

The website demonstrates the prototype; it does not provide cross-site upload monitoring. Exact matching detects only unchanged bytes. The extension cannot prevent screenshots, photos from another device, or every form of disclosure.
